ОТЧЁТ ПО ПРАКТИЧЕСКИМ РАБОТАМ №1-7


1. Описание реализации и модулей:
Проект представляет собой полноценное веб-приложение для управления списком задач (Task Manager) с полной поддержкой всех операций CRUD (Create, Read, Update, Delete) через браузер. Логика защищена от сбоев базы данных механизмами обработки исключений.

Состав файлов в корневой папке проекта:
- app.py: Главный скрипт веб-сервера на Flask. Реализует маршруты для добавления задач, отметки их выполненными (UPDATE) и удаления (DELETE) по динамическим ID. Использует паттерн PRG для защиты от дублирования данных.
- app.db: Физический файл реляционной базы данных SQLite, хранящий таблицу tasks.
- init_db.py: Скрипт первоначальной инициализации структуры БД.
- check_db.py: Утилита для верификации таблиц.
- crud_console.py: Консольный CRUD-клиент для прямого администрирования базы.
- templates/index.html: Фронтенд-шаблон Jinja2 с динамической версткой интерактивных кнопок и формами отправки POST-запросов.

2. Использованные технологии:
- Язык программирования: Python 3
- СУБД: SQLite (модуль sqlite3)
- Веб-фреймворк: Flask
- Шаблонизатор: Jinja2 (условия, циклы, динамические классы CSS)
- Стилизация интерфейса: CSS3
