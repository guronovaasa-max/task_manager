1Зачем нужен шаблонизатор Jinja2, если можно вернуть HTML-строку из функции?
ответ: Чтобы не смешивать логику Python и внешний вид сайта (HTML). Писать большой HTML-код со стилями внутри Python-файла неудобно, его тяжело читать и редактировать. Jinja2 позволяет вынести верстку в отдельные файлы и удобно вставлять туда данные.


2Чем {{ ... }} отличается от {% ... %} в Jinja2?
ответ: Двойные фигурные скобки {{ ... }} используются для вывода данных на страницу (например, переменной {{ item.title }}).
С фигурные скобки с процентами {% ... %} используются для логических инструкций — циклов и условий (например, {% for ... %} или {% if ... %}).


3Что делает render_template('index.html', items=rows)?
ответ: Она берет файл index.html из папки templates, обрабатывает его с помощью Jinja2 (заменяет циклы и переменные на реальные данные из списка rows, который внутри шаблона будет называться items) и отдает браузеру готовую HTML-страницу.

4Почему при чтении данных не нужен conn.commit()?
ответ: Потому что commit() нужен только для фиксации изменений (когда мы что-то добавляем, обновляем или удаляем). Запрос чтения SELECT ничего в файле базы данных не меняет, поэтому сохранять нечего.


5Что такое sqlite3.Row и почему item.title работает только с ним?
ответ: По умолчанию SQLite возвращает строки в виде простых кортежей, где к данным можно обратиться только по индексам (item[1]). Настройка conn.row_factory = sqlite3.Row заставляет Python возвращать строки, похожие на словари, что позволяет читать данные красиво — по именам колонок из таблицы (item['title'] или в Jinja2 как item.title).

6Куда Flask кладёт файлы шаблонов по умолчанию и можно ли это изменить?
ответ: По умолчанию Flask ищет их в папке templates, которая должна лежать в одной директории с запускаемым файлом app.py. Да, это можно изменить при создании приложения, передав другой путь в параметр: app = Flask(__name__, template_folder='имя_папки').

7Что выведет шаблон, если items — пустой список?
ответ: Сработает блок условия {% else %} из HTML-файла, и на странице отобразится текст: «Список пуст. Добавь первую задачу!».
