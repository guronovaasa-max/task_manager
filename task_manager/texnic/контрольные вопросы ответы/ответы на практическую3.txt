1Что делает декоратор @app.route('/')?
ответ: Он связывает (мэппит) URL-адрес в браузере с конкретной функцией в коде Python. В данном случае он указывает, что при переходе на главную страницу / должна сработать функция index().

2Чем GET отличается от POST? Какой метод используется по умолчанию?
ответ:  GET используется для получения данных с сервера (например, открыть страницу, посмотреть список задач). Данные передаются прямо в адресной строке.
POST используется для отправки данных на сервер (например, отправить заполненную форму, добавить задачу). Данные скрыты в теле запроса.
По умолчанию Flask для всех маршрутов использует метод GET


3 Зачем нужен debug=True и почему его нельзя использовать на реальном сервере?
ответ:  Он включает режим отладки, который автоматически перезапускает сервер при изменении кода и показывает детальные ошибки прямо в браузере. Его нельзя использовать на реальном сервере (в продакшене), потому что интерактивный отладчик позволяет любому пользователю увидеть внутреннюю структуру кода и даже выполнить вредоносный код на сервере.

4Что означает адрес 127.0.0.1:5000?
ответ:  127.0.0.1это IP-адрес localhost (локальная петля), который означает «этот самый компьютер».
5000 — это номер порта, который слушает наше веб-приложение Flask, чтобы не путать его с другими программами.


5Почему при открытии /nonexistent мы получаем 404, а не ошибку Python?
ответ:  Потому что Flask сам перехватывает этот запрос. Он сверяет адрес со списком зарегистрированных маршрутов в коде, понимает, что такого пути нет, и корректно возвращает стандартный HTTP-статус 404 (Not Found) вместо аварийного завершения работы скрипта.


6Почему папка для HTML-шаблонов должна называться именно templates?
ответ:  Это стандартное имя по умолчанию, которое зашито во внутреннюю логику Flask. Функция render_template() автоматически ищет HTML-файлы именно в папке с таким названием, расположенной рядом со скриптом.

7Что произойдёт, если запустить два сервера Flask одновременно на одном порту?
ответ:  Второй сервер вылетит с ошибкой (например, OSError: [Errno 98] Address already in use). Операционная система не позволяет двум разным программам занимать один и тот же сетевой порт одновременно.
